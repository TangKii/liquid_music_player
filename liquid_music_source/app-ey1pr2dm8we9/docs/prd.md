# 需求文档

## 1. 应用概述

### 1.1 应用名称
液态音乐播放器（Liquid Music Player）

### 1.2 应用描述
液态音乐播放器是一款 Android 本地与内置音频播放应用，最终产物为可独立安装的 APK 安装包。应用采用液态玻璃视觉风格，提供内置精选歌单播放、多本地文件夹扫描导入、全屏播放控制以及同步歌词滚动展示等功能，满足用户简洁流畅的本地音乐收听需求。

## 2. 用户与使用场景

### 2.1 目标用户
- 拥有本地音频文件并使用 Android 手机的用户
- 偏好简洁播放控制与歌词同步查看体验的用户

### 2.2 核心使用场景
- **内置歌曲播放**：启动应用后直接收听应用内置精选音频。
- **本地音频导入**：指定一个或多个本地文件夹，自动扫描音频并生成播放列表。
- **全屏沉浸播放**：展开全屏播放页，查看旋转唱片效果、拖拽进度条及查看同步滚动的歌词。

## 3. 页面结构与功能说明

### 3.1 页面层级结构
```
液态音乐播放器
├── 1. 主页面
│   ├── 1.1 精选歌单列表
│   ├── 1.2 本地音乐列表
│   ├── 1.3 文件夹管理入口
│   └── 1.4 底部悬浮播放栏
├── 2. 文件夹管理页面
│   ├── 2.1 添加本地文件夹
│   └── 2.2 已选文件夹列表与移除
└── 3. 全屏播放页面
    ├── 3.1 专辑封面与旋转唱片
    ├── 3.2 歌词同步滚动区域
    ├── 3.3 播放控制与进度调节
    └── 3.4 收起/返回控制
```

### 3.2 页面功能说明

#### 3.2.1 主页面
- **精选歌单**：展示内置示例音频列表（包含封面、歌曲名、歌手、时长），点击任意条目即可切换并播放对应音频。
- **本地音乐列表**：展示已扫描导入的本地音频列表，条目显示去除扩展名后的歌曲名称及所在文件夹名称，支持点击播放与列表去重展示。
- **文件夹管理入口**：提供跳转至文件夹管理页面的入口按钮。
- **底部悬浮播放栏**：常驻页面底部，展示当前播放歌曲的封面、歌名及播放/暂停控制按钮；点击悬浮栏整体可展开全屏播放页面。

#### 3.2.2 文件夹管理页面
- **添加本地文件夹**：调用系统文件夹选择器，支持用户指定一个或多个本地存储文件夹。
- **已选文件夹列表**：展示当前已添加的文件夹路径列表，支持单个文件夹的移除操作。
- **扫描更新机制**：添加或移除文件夹后，自动递归扫描对应文件夹（含子文件夹）中的音频文件（支持 .mp3, .wav, .flac, .m4a, .aac, .ogg 等格式），并实时更新主页面的本地音乐列表。

#### 3.2.3 全屏播放页面
- **专辑封面与旋转唱片**：展示大尺寸专辑封面与唱片视觉效果，播放时持续旋转，暂停时停止旋转。
- **歌词同步滚动**：按播放进度毫秒时间戳匹配并高亮当前句歌词，支持随播放进度垂直自动居中滚动。
- **核心播放控制**：提供播放/暂停、上一首、下一首切换按钮。
- **进度调节**：展示当前播放时间与音频总时长，支持拖动进度条进行音频跳转播放。
- **收起页面**：提供收起/返回按钮，点击后关闭全屏并返回主页面，不中断当前音频播放状态。

## 4. 业务规则与核心逻辑

### 4.1 核心播放与列表规则
1. **内置歌曲即开即播**：应用安装完成后内置真实可播放音频数据，未导入本地音乐时仍可正常使用基础播放能力。
2. **多文件夹扫描与去重**：扫描本地文件夹时，按文件绝对路径进行排重处理；当移除某已选文件夹时，同步清理该文件夹及其子目录下的本地音乐条目。
3. **歌词检索与匹配**：本地音频优先在同目录下查找同名 `.lrc` 文件；未找到或为内置歌曲时，加载内置歌词；均无可用歌词时展示暂无歌词提示。
4. **歌词时间戳对齐**：根据音频当前播放时间戳实时对齐歌词行，平滑高亮并滚动至可视区域中心。

## 5. 异常与边界情况

| 场景 | 异常情况 | 处理策略 |
| :--- | :--- | :--- |
| 文件夹扫描 | 选中的文件夹内无任何支持的音频文件 | 保留该文件夹记录，提示未扫描到音频文件，不中断后续操作 |
| 本地音频播放 | 音频文件在外部被删除或移动 | 播放时提示文件不存在，自动跳过并尝试播放下一首歌曲 |
| 歌词加载 | `.lrc` 文件损坏或时间戳解析异常 | 降级显示歌词文本或提示歌词解析失败，不影响音频正常播放 |
| 权限申请 | 用户拒绝系统文件/存储访问权限 | 提示需要存储权限以扫描本地音频，精选歌单仍保持可用 |

## 6. 验收标准

1. 应用可成功打包为 Android APK 并在 Android 设备上顺利安装启动。
2. 点击精选歌单中的歌曲可正常出声播放，上一首、下一首、播放/暂停与进度条拖拽均可正确响应。
3. 支持通过文件夹选择器添加多个本地文件夹，能够递归扫描识别多格式音频并展示于本地列表中。
4. 移除指定文件夹后，本地音乐列表中对应的歌曲条目实时被移除且不可继续播放。
5. 点击底部悬浮播放栏可展开全屏播放页，唱片旋转状态与播放/暂停控制保持同步。
6. 存在匹配 `.lrc` 文件时，全屏播放页中歌词随时间戳准确高亮并同步滚动展示。
